## Deskripsi
Untuk tugas UTS kali ini saya membuat web I-Gudang, dimana web tersebut adalah web pengelolaan gudang berbasis Laravel dengan Blade dan Tailwind CSS. Pengguna dapat melakukan login dengan username, lalu bisa melihat dashboard, profil, dan daftar data barang gudang.
